# 6.3. Pruebas Unitarias

### 6.3.1. Definición de Clases de Equivalencia y Valores Límite

Para diseñar los casos de prueba unitarios se seleccionaron dos operaciones de alta criticidad financiera y operativa:
1.  **Operación `abrirSesionCaja(montoBase)`:** Establece el fondo inicial de cambio en efectivo.
2.  **Operación `agregarItem(idProducto, cantidad)`:** Incorpora unidades de producto a una comanda.

#### Partición de Clases de Equivalencia para `abrirSesionCaja(montoBase)`
*   **CE1 (Válida):** $0.00 \le \text{montoBase} \le 1000000.00$ (Monto numérico no negativo dentro del límite operativo de caja).
*   **CE2 (Inválida - Negativa):** $\text{montoBase} < 0.00$ (Valores negativos que violarían la invariante de caja).
*   **CE3 (Inválida - Excesiva):** $\text{montoBase} > 1000000.00$ (Fondo inicial superior al cupo máximo de seguridad permitido en efectivo).
*   **CE4 (Inválida - No numérica / Nula):** $\text{montoBase} = \text{null}$ o no numérico.

#### Análisis de Valores Límite (BVA)
*   Límite inferior: $-0.01$ (inválido), $0.00$ (límite válido), $0.01$ (válido).
*   Límite superior: $999999.99$ (válido), $1000000.00$ (límite válido), $1000000.01$ (inválido).

### 6.3.3. Pruebas de Caja Blanca

Se somete a análisis de flujo de control y cobertura de caminos básicos al método **`calcularArqueo(montoFisicoEfectivo)`** de la clase `SesionCaja`.

#### Lógica interna del método (Pseudocódigo):
```text
1:  saldoTeorico = montoInicial + totalVentasEfectivo;
2:  diferencia = montoFisicoEfectivo - saldoTeorico;
3:  if (diferencia == 0) {
4:      resultadoArqueo = "Exacto";
    } else {
5:      if (diferencia > 0) {
6:          resultadoArqueo = "Sobrante";
        } else {
7:          resultadoArqueo = "Faltante";
        }
    }
8:  setEstado("Cerrada");
9:  return resultadoArqueo;
```

#### Grafo de Flujo y Caminos Posibles:
*   **Camino 1 (Balance Exacto):** $1 \rightarrow 2 \rightarrow 3 \rightarrow 4 \rightarrow 8 \rightarrow 9$
*   **Camino 2 (Sobrante de Efectivo):** $1 \rightarrow 2 \rightarrow 3 \rightarrow 5 \rightarrow 6 \rightarrow 8 \rightarrow 9$
*   **Camino 3 (Faltante de Efectivo):** $1 \rightarrow 2 \rightarrow 3 \rightarrow 5 \rightarrow 7 \rightarrow 8 \rightarrow 9$

#### Tabla Resumen de Pruebas de Caja Blanca

| Camino | Condición Evaluada | Entradas (clase / rango) | Resultado esperado |
| :---: | :--- | :--- | :--- |
| **Camino 1** | `diferencia == 0` | `saldoTeorico = 50000.00`<br>`montoFisico = 50000.00` | `diferencia = 0.00`<br>`resultadoArqueo = "Exacto"`. Sesión cerrada. |
| **Camino 2** | `diferencia > 0` | `saldoTeorico = 50000.00`<br>`montoFisico = 51200.00` | `diferencia = +1200.00`<br>`resultadoArqueo = "Sobrante"`. Sesión cerrada. |
| **Camino 3** | `diferencia < 0` | `saldoTeorico = 50000.00`<br>`montoFisico = 48500.00` | `diferencia = -1500.00`<br>`resultadoArqueo = "Faltante"`. Sesión cerrada. |

*Cobertura alcanzada: 100% de caminos independientes (Complejidad Ciclomática $V(G) = 3$).*
