# 6.4. Pruebas de Integración

Las pruebas de integración verifican la interacción correcta entre múltiples capas y servicios acoplados (Frontend React, Backend Laravel, Base de Datos PostgreSQL y Servicios Web Externos).

---

### Casos de Prueba de Integración

| Caso | Módulos Involucrados | Entradas | Resultado esperado |
| :---: | :--- | :--- | :--- |
| **INT-01** | `VentaService`<br>`InventarioService`<br>`PostgreSQL` | Confirmación de venta de 3 Hamburguesas Dobles (con receta de 2 medallones, 2 fetas cheddar y 1 pan c/u). | Transacción ACID completa: Se crea la comanda, se asienta el pago y se descuentan atómicamente del inventario 6 medallones, 6 fetas cheddar y 3 panes. |
| **INT-02** | `VentaService`<br>`AFIPService` (Mock/Homologación)<br>`PostgreSQL` | Cobro de venta con solicitud de factura electrónica fiscal. | Se emite la petición SOAP/JSON a AFIP Homologación, se recibe el CAE y fecha de vencimiento válidos, y se persiste el comprobante fiscal asociado a la venta. |
| **INT-03** | `ReabastecimientoJob`<br>`ServicioCorreo`<br>`PostgreSQL` | Ejecución programada del cron nocturno con 2 insumos bajo punto de pedido. | El servicio detecta insumos críticos, recupera los correos de proveedores vinculados y despacha el pliego de cotización vía SMTP sin intervención humana. |
| **INT-04** | `FidelizacionJob`<br>`PlataformaMensajeria`<br>`PostgreSQL` | Detección de clientes con 65 días de inactividad comercial. | El sistema genera el código de cupón promocional en base de datos y despacha la notificación a la API de mensajería al número telefónico del cliente. |
| **INT-05** | `VentaService`<br>`KdsBroadcasting`<br>`React KDS Client` | Transacción de venta confirmada en terminal POS mostrador. | El backend despacha un evento `ComandaCreadaEvent` mediante WebSockets (Laravel Reverb / Echo); el monitor KDS de cocina recibe el payload en < 300 ms e inserta la tarjeta del pedido reactivamente. |
| **INT-06** | `VentaService`<br>`AFIPService`<br>`InventarioService`<br>`PostgreSQL` | Solicitud de anulación de ticket con motivo fundamentado (CU-05). | Se solicita y asienta la Nota de Crédito electrónica con CAE de AFIP, se cambia el estado de la venta a 'Anulada' y se reincorporan las materias primas consumidas al `stockActual` de PostgreSQL. |
