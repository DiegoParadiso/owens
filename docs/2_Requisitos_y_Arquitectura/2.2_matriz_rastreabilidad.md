# 2.2 Matriz de Rastreabilidad (Trazabilidad 2D)

Siguiendo los lineamientos del **Proceso Unificado Ágil (AUP)** y el enfoque de **Desarrollo Guiado por Especificaciones (SDD)**, es mandatorio asegurar que cada línea de código y cada Caso de Uso construido responda a una necesidad real del negocio.

Para garantizar esta alineación estratégica, se utiliza una **Matriz de Rastreabilidad 2D**. Esta herramienta cruza los Objetivos Específicos del Sistema (definidos en la sección 1.1.3) con los Casos de Uso Críticos y Altos (definidos en la priorización de la sección 1.5.5). 

La intersección indica el nivel de importancia (Alta, Media, Baja) que tiene el Caso de Uso para cumplir con ese objetivo de negocio específico. Esta matriz actúa como el respaldo teórico que justifica los puntajes de "Valor de Negocio (BV)" asignados anteriormente, alineándose con las prácticas de priorización orientadas a objetivos (*Goal-Oriented Prioritization*) respaldadas por la literatura de ingeniería de software (Odeh & Al-Saiyd, 2023).
