### 3.3 Especificación de Casos de Uso Críticos

#### Caso de Uso: UC-46 Generar Solicitud de Cotización (Módulo Inteligente de Reabastecimiento)

**Objetivos Asociados**
*   **OBJ-04** Automatizar el reabastecimiento de insumos críticos.

**Actor Principal**
Planificador.
*(Actores Secundarios: Servicio de Correo, Proveedor)*

**Precondición**
*   Se alcanzó el momento programado para la revisión periódica de existencias.
*   Existen registros históricos de precios de insumos asociados a proveedores.

**Intención del Actor**
Identificar de forma autónoma las materias primas cuyas existencias alcanzaron el punto de pedido (nivel mínimo de reposición) y generar solicitudes de cotización al proveedor que ofrezca las condiciones más convenientes, asegurando la continuidad del abastecimiento del local.

**Propósito del Sistema**
Revisar las cantidades disponibles de insumos, detectar aquellos que alcanzaron o cayeron por debajo de su nivel de reposición mínimo, seleccionar al proveedor más económico según el historial comercial, generar los documentos formales de solicitud y remitirlos desatendidamente a través del servicio de correo.

**Descripción General**
El proceso autónomo evalúa los niveles de inventario. Al identificar insumos en nivel crítico, consulta el historial de compras para determinar qué proveedores distribuyen dichos artículos y cuál registró el menor precio. Conforma una solicitud de cotización formal y la despacha al proveedor correspondiente mediante el servicio de correo, asentando la acción en el registro de auditoría.

**Secuencia Normal**
| Paso | Acción |
| :--- | :--- |
| 1 | El caso de uso inicia cuando el Planificador activa la rutina periódica de control de existencias. |
| 2 | El Sistema identifica los insumos cuya cantidad disponible es igual o inferior al nivel de reposición mínimo configurado. |
| 3 | Por cada insumo en estado crítico, el Sistema recupera el historial de precios y los proveedores vinculados. |
| 4 | El Sistema evalúa los antecedentes comerciales y selecciona al proveedor con el precio de compra más conveniente. |
| 5 | El Sistema asigna los insumos correspondientes al proveedor seleccionado para la reposición. |
| 6 | El Sistema elabora un documento formal de Solicitud de Cotización agrupando los insumos requeridos por cada proveedor. |
| 7 | El Sistema despacha la solicitud al proveedor a través del Servicio de Correo. |
| 8 | El Sistema asienta la emisión de la solicitud en la pista de auditoría para la supervisión gerencial. El caso de uso finaliza. |

**Postcondición**
*   Se despacharon las solicitudes de cotización a los proveedores seleccionados.
*   Se registró la gestión autónoma en la pista de auditoría del sistema.

**Excepciones**
| Paso | Acción |
| :--- | :--- |
| 3 | **Insumo sin Proveedor Asignado:** Si un insumo crítico no cuenta con proveedores vinculados o carece de antecedentes de precios, el sistema genera una alerta de abastecimiento dirigida al Administrador para su resolución manual. **El caso de uso regresa al paso 3** para continuar con el siguiente insumo. |
| 7 | **Falla en el Servicio de Correo:** Si el servicio de correo no se encuentra disponible o no es posible concretar la entrega, el sistema suspende el envío y marca la solicitud como pendiente para un próximo reintento autónomo. **El caso de uso finaliza.** |

**Rendimiento**
| Paso | Cota de tiempo |
| :--- | :--- |
| 1-8 | Proceso desatendido en segundo plano; no interfiere con la atención en mostrador. |

**Frecuencia**
Baja (Generalmente una vez al día fuera del horario pico comercial).

**Estabilidad**
Alta.

**Comentarios**
Este caso de uso es uno de los tres Módulos Inteligentes del sistema. Reduce costos operativos y previene el desabastecimiento de insumos clave al automatizar la comparación de precios y la emisión de solicitudes sin requerir intervención humana constante.
