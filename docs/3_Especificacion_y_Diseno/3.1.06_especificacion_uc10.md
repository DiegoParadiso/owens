# 3.1.6 Especificación de Caso de Uso UC-10: Visualizar Comandas de Producción (KDS)

**Objetivos Asociados**
*   **OBJ-01** Optimizar la atención en el Punto de Venta (POS).
*   **OBJ-02** Controlar el inventario mediante recetas.

**Requisitos Asociados**
*   **NFR-01** Rendimiento y Tiempos de Respuesta.
*   **NFR-04** Usabilidad e Interfaz Adaptativa (Pantalla de Cocina).

**Actor Principal**
Cocinero.
*(Actor Secundario: Cajero)*

**Precondición**
*   El usuario inició sesión en el sistema con rol de Cocinero (`<<include>> UC-36`).
*   Existen órdenes confirmadas pendientes de elaboración.

**Intención del Actor**
Ver las órdenes de comida pendientes, consultar los platos solicitados, actualizar el estado de preparación y avisar al mostrador cuando los pedidos estén listos.

**Propósito del Sistema**
Mostrar las comandas ordenadas por horario de llegada, actualizar los estados de elaboración y comunicar al personal de atención cuando el pedido esté listo para entrega.

**Descripción General**
El Cocinero visualiza en la pantalla de cocina las órdenes recibidas desde el punto de venta o pedidos digitales. Selecciona una comanda al iniciar la cocción y, al terminarla, la marca como lista para entrega para avisar al mostrador.

**Secuencia Normal**
| Paso | Acción |
| :--- | :--- |
| 1 | El caso de uso inicia cuando el Cocinero accede a la pantalla de cocina. |
| 2 | El Sistema consulta las órdenes confirmadas pendientes de elaboración. |
| 3 | El Sistema muestra las comandas ordenadas por horario, indicando número de pedido, tiempo transcurrido, platos e instrucciones de preparación. |
| 4 | El Cocinero selecciona una comanda para iniciar su preparación. |
| 5 | El Sistema actualiza el estado de la comanda a "En Preparación" y lo comunica al mostrador. |
| 6 | El Cocinero finaliza la elaboración y confirma el despacho del pedido. |
| 7 | El Sistema marca la orden como "Lista para Entrega", guarda el horario de finalización y notifica al personal de mostrador. |
| 8 | El Sistema retira la comanda de la pantalla activa y actualiza la lista restante de pedidos. El caso de uso finaliza. |

**Postcondición**
*   Se actualizó el estado de la orden a "Lista para Entrega".
*   Se registró el horario de finalización del pedido.
*   El personal de mostrador recibió el aviso de pedido listo.

**Excepciones**
| Paso | Acción |
| :--- | :--- |
| 2 | **Sin Pedidos Pendientes:** Si no hay órdenes pendientes de elaboración, el sistema informa que no hay pedidos en espera. **El caso de uso regresa al paso 2.** |
| 3-6 | **Anulación de Pedido:** Si una orden es anulada desde el punto de venta (`<<include>> UC-05`), el sistema retira la comanda de la pantalla de cocina y avisa al Cocinero. **El caso de uso regresa al paso 3.** |

**Rendimiento**
| Paso | Cota de tiempo |
| :--- | :--- |
| 2-3 | Menor a 1 segundo para mostrar nuevos pedidos. |
| 5, 7 | Actualización de estados menor a 1 segundo. |

**Frecuencia**
Continua durante toda la jornada de atención.

**Estabilidad**
Alta.

**Comentarios**
Permite gestionar la cocina mediante pantalla táctil, reemplazando la impresión de comandas en papel y agilizando la comunicación con el mostrador.
