# 3.1.8 Especificación de Caso de Uso UC-16: Registrar Producción Interna

**Objetivos Asociados**
*   **OBJ-02** Controlar el inventario mediante recetas.
*   **OBJ-03** Digitalizar la gestión de compras y existencias.
*   **OBJ-07** Garantizar la seguridad, integridad y auditoría de los datos (Trazabilidad Bromatológica).

**Actor Principal**
Encargado de Depósito / Administrador.

**Precondición**
*   El usuario inició sesión en el sistema (`<<include>> UC-36`).
*   Existe una receta vigente para el artículo a elaborar.
*   Existen lotes disponibles de materias primas con existencias no vencidas para cada ingrediente requerido.

**Intención del Actor**
Declarar la elaboración física de un lote de artículos (como medallones caseros, aderezos o hamburguesas armadas), registrando su fecha de elaboración y vencimiento, y vinculando los lotes exactos consumidos de materias primas para garantizar la trazabilidad bromatológica.

**Propósito del Sistema**
Crear el registro del nuevo lote elaborado, calcular su fecha de vencimiento según la vida útil de conservación del artículo, descontar las cantidades de los lotes de ingredientes utilizados y almacenar el historial de materias primas consumidas para asegurar la trazabilidad bromatológica.

**Descripción General**
El Encargado selecciona el artículo a elaborar y el sistema expone la fórmula vigente y los lotes disponibles de cada ingrediente. El usuario ingresa la cantidad a producir y confirma los lotes de ingredientes a utilizar (mediante sugerencia de primeros en vencer o selección manual). El sistema registra el nuevo lote elaborado y descuenta las cantidades de los lotes de ingredientes utilizados.

**Secuencia Normal**
| Paso | Acción |
| :--- | :--- |
| 1 | El caso de uso inicia cuando el Encargado de Depósito solicita registrar una producción de artículos elaborados. |
| 2 | El Sistema solicita la selección del artículo a elaborar. |
| 3 | El Encargado busca y selecciona el artículo (`<<include>> UC-53: Buscar Producto / Insumo`). |
| 4 | El Sistema recupera la fórmula vigente a la fecha, expone la lista de ingredientes y solicita la cantidad total a elaborar. |
| 5 | El Encargado ingresa la cantidad de unidades o porciones a elaborar. |
| 6 | El Sistema calcula la cantidad requerida de cada ingrediente, sugiere los lotes de materias primas disponibles priorizando los primeros en vencer y solicita confirmación. |
| 7 | El Encargado revisa o ajusta los lotes específicos utilizados en la preparación y confirma la operación. |
| 8 | El Sistema registra el nuevo lote elaborado con la fecha actual, la cantidad producida y la fecha de vencimiento calculada. |
| 9 | El Sistema descuenta las cantidades consumidas de los lotes de ingredientes y asienta la trazabilidad de las materias primas utilizadas en la preparación. |
| 10 | El Sistema actualiza el inventario y asienta la operación en el registro de auditoría. |
| 11 | El Sistema confirma el registro exitoso del lote con su identificador y finaliza el caso de uso. |

**Postcondición**
*   Se da de alta un nuevo lote de producto elaborado disponible para la venta o consumo en preparaciones posteriores.
*   Queda resguardada la trazabilidad completa de los ingredientes utilizados, permitiendo identificar el origen de las materias primas consumidas ante auditorías sanitarias o controles de calidad.

**Excepciones**
| Paso | Acción |
| :--- | :--- |
| 4 | **Inexistencia de Receta Vigente:** Si el artículo seleccionado no posee una receta activa a la fecha, el sistema notifica el impedimento y sugiere registrarla mediante UC-15. **El caso de uso finaliza.** |
| 6 | **Existencias Insuficientes o Vencidas:** Si no existen lotes disponibles con cantidad suficiente o se detecta que los lotes existentes están vencidos, el sistema alerta al usuario detallando los ingredientes afectados. **El caso de uso regresa al paso 5.** |
| 8-9 | **Error de Concurrencia en Stock:** Si otro usuario consume el lote seleccionado en el mismo instante, la transacción se revierte de forma atómica y se solicita revalidar los lotes disponibles. **El caso de uso regresa al paso 6.** |

**Rendimiento**
| Paso | Cota de tiempo |
| :--- | :--- |
| 6-10 | Menor a 1.5 segundos. |

**Frecuencia**
Diaria (Turnos matutinos de preparación de cocina o mise en place).

**Estabilidad**
Alta.

**Comentarios**
Este flujo constituye el núcleo de la trazabilidad bromatológica exigida por normativas sanitarias y solicitada por la cátedra: permite rastrear en segundos qué lote de carne molida o huevo se utilizó para producir un medallón específico servido al cliente.
