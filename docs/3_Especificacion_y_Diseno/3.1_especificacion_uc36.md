### 3.1 Especificación de Casos de Uso Críticos

#### Caso de Uso: UC-36 Autenticar Usuario

**Objetivos Asociados**
*   **OBJ-07** Garantizar la seguridad, integridad y auditoría de los datos.


**Actor Principal**
Usuario (Clase abstracta de la cual heredan Administrador, Cajero, Encargado, etc.).

**Precondición**
*   Existe al menos un usuario registrado y activo en el sistema.

**Intención del Actor**
Identificarse en el sistema para obtener acceso a las funciones operativas correspondientes a su rol.

**Propósito del Sistema**
Validar las credenciales provistas, gestionar el ciclo de vida de la sesión segura y aplicar los filtros de autorización (RBAC).

**Descripción General**
El Usuario provee sus credenciales. El sistema verifica la identidad contra la base de registros, establece una sesión segura y direcciona al usuario a su panel correspondiente según los permisos asignados.

**Secuencia Normal**
| Paso | Acción |
| :--- | :--- |
| 1 | El caso de uso inicia cuando el Usuario solicita ingresar al sistema. |
| 2 | El Sistema solicita identificador y contraseña. |
| 3 | El Usuario ingresa sus credenciales y confirma el acceso. |
| 4 | El Sistema verifica que el identificador exista y que la contraseña coincida con los registros de seguridad. |
| 5 | El Sistema verifica que el usuario se encuentre en estado "Activo" (no suspendido o de baja). |
| 6 | El Sistema registra el evento en la auditoría, concede el acceso y finaliza el caso de uso. |

**Postcondición**
*   Se concedió acceso seguro al sistema.
*   Los privilegios del usuario quedaron cargados en la sesión activa.

**Excepciones**
| Paso | Acción |
| :--- | :--- |
| 4 | **Credenciales Inválidas:** Si la validación de seguridad falla o el usuario no existe, el sistema deniega el acceso e informa un error genérico ("Credenciales incorrectas"). **El caso de uso regresa al paso 3.** |
| 5 | **Usuario Inactivo:** Si el usuario se encuentra suspendido o dado de baja lógicamente, el sistema deniega el acceso e informa del bloqueo. **El caso de uso finaliza.** |

**Rendimiento**
| Paso | Cota de tiempo |
| :--- | :--- |
| 4 | Verificación de credenciales < 1 segundo. |

**Frecuencia**
Alta (Al inicio de la jornada o reanudación de sesión inactiva).

**Estabilidad**
Alta.

**Comentarios**
Es el caso de uso base fundamental que se invoca (mediante `<<extend>>` o implícitamente) en absolutamente toda operación protegida del sistema.
