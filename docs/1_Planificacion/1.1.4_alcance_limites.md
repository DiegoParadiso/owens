# 1.1.4 Alcance y Límites del Sistema

El sistema "Owens" abarca la gestión integral del ciclo comercial del establecimiento, operando sobre el modelo de atención rápida por mostrador (Fast-Food). Su alcance funcional cubre la toma de pedidos en el Punto de Venta (POS), la visualización de comandas en tiempo real para producción (KDS), el descuento automático de inventario mediante explosión de recetas, la digitalización de compras, la facturación electrónica, la emisión de reportes estadísticos y el control estricto mediante pistas de auditoría inmutables.

Adicionalmente, el alcance del sistema contempla la parametrización integral de catálogos base (ABMs menores). Aunque estas operaciones no se detallan como Casos de Uso transaccionales complejos, el sistema provee las interfaces y controladores necesarios para administrar: Categorías de Productos, Categorías de Gastos, Métodos de Pago y Unidades de Medida.

Para acotar el proyecto a un marco viable y evitar desviaciones funcionales, se establecen los siguientes límites (funcionalidades fuera de alcance):

*   **Gestión de Mesas Físicas:** Al estar orientado al modelo Fast-Food, el sistema no contempla un mapa interactivo para ruteo o asignación de mesas en el salón.
*   **Procesamiento de pagos:** El sistema asienta el medio de cobro, pero no procesa transacciones nativas con tarjetas; esto dependerá de terminales externas (Posnet/MercadoPago).
*   **Recursos Humanos:** No se incluye la liquidación de sueldos, diagramación de turnos ni control de presentismo del personal.
*   **Logística de Envíos:** No contempla un módulo de ruteo o seguimiento GPS para cadetes o repartidores.
