# 6. Procesos Automatizados

A continuación se describen los módulos inteligentes (procesos automatizados e integraciones) del sistema. Cada proceso es considerado un módulo inteligente en tanto genera valor agregado real para el proyecto, no forma parte de la versión mínima viable (MVP) del sistema, trasciende la lógica de una simple consulta a la base de datos, se compone de una secuencia encadenada de pasos y requiere la intervención articulada de múltiples módulos.

| Denominación | Módulos que intervienen | Descripción |
| :--- | :--- | :--- |
| **PA-1: Generación de Solicitud de Cotización**<br>*Paradiso, Diego* | • Módulo de Logística e Inventario<br>• Módulo de Interfaces Externas | **Disparador:** El planificador autónomo se ejecuta a medianoche (00:00).<br>**Pasos:** (1) El sistema audita el inventario contra el punto de pedido; (2) Identifica a los proveedores asociados al insumo faltante; (3) Renderiza un documento PDF formal (RFQ); (4) Se conecta al protocolo SMTP y envía el correo con el adjunto automáticamente a los proveedores. |
| **PA-2: Enviar Cupón de Fidelización**<br>*Paradiso, Diego* | • Módulo de Operaciones y Ventas<br>• Módulo de Interfaces Externas | **Disparador:** Evaluación diaria del padrón de clientes (01:00 AM).<br>**Pasos:** (1) El sistema calcula los días de inactividad de cada cliente; (2) Si supera los 30 días, genera un cupón de descuento paramétrico; (3) Se conecta con la API REST de Mensajería Externa y despacha la notificación promocional directamente al smartphone del cliente. |
| **PA-3: Autorización Fiscal Electrónica (AFIP)**<br>*Paradiso, Diego* | • Módulo de Operaciones y Ventas<br>• Módulo de Interfaces Externas | **Disparador:** Confirmación de cobro por parte del cajero.<br>**Pasos:** (1) El sistema compila los datos de la transacción en formato XML; (2) Firma digitalmente el paquete con el certificado X.509; (3) Se conecta vía protocolo SOAP al Web Service de AFIP (WSFEv1); (4) AFIP procesa y devuelve el CAE (Código de Autorización Electrónico) para imprimir el ticket fiscal. |
